Styling Classes:

class names: CamelCase
instance names & module names: underscores & lowercase

docstrings: 
immediately after class definition
brief description of what the class does
each module should have a docstring that describes what the classes in module should do.

blank line organization:
class: one blank line between methods
module: two blank lines to separate classes.
